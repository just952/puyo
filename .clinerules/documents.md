- 프로젝트의 정보와 진행 상황은 ./docs 경로에 있는 아래 파일들을 참고한다.
  1. design.md 에는 게임 기획 (장르, 메커니즘, 게임 모드, 스토리, AI, UI/UX, 사운드, 확장 계획) 
  2. architecture.md 는 기술 스택, 프로젝트 구조, 아키텍처 패턴, 빌드/배포, 테스트 전략 
  3. progress.md 는현재 진행 현황 (완료/진행중/백로그/이슈/마일스톤)
  4. todo.md 는 남은 작업 목록 (P0~P2 우선순위, 알려진 이슈, 마일스톤)
  5. changeLog.md 는 버전별 변경 이력 
  6. proposal.md 는 최초 제안서 (현재와는 좀 다를수 있음)
- 문서 현행화는 무턱대고 진행하지 말고 필요하다고 판단될 경우 나한테 할 건지 물어볼 것.
