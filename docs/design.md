# Puyo Puyo 2 - 게임 기획 문서

## 게임 개요

- **장르**: 실시간 퍼즐 대전 (매치-3 + 연쇄 시스템)
- **원작**: 컴파일(Compile) 1994년작 "뿌요뿌요 통( Puyo Puyo Tsu )"
- **타겟**: 안드로이드(메인) / 데스크톱(개발용)
- **핵심 재미**: 4개 이상 같은 색 뿌요 연결 → 연쇄(Chain) → 상대에게 방해 뿌요(오자마) 보내기

---

## 핵심 게임플레이 메커니즘

### 기본 규칙

- **보드**: 6열 × 12행 (가로 6, 세로 12)
- **뿌요**: 5가지 색상 (빨강, 초록, 파랑, 노랑, 보라) + 방해 뿌요(회색) + 하드 뿌요
- **조작**: 좌/우 이동, 회전(시계/반시계), 소프트 드롭(아래), 하드 드롭(스페이스)
  - **DAS (Delayed Auto Shift)**: 키 누름 16프레임(~0.27초) 후 자동 반복 시작
  - **ARR (Auto Repeat Rate)**: 2프레임마다 1칸씩 반복 이동 (초당 30회)
- **매칭**: 상하좌우 4개 이상 같은 색 연결 시 제거
- **연쇄(Chain)**: 제거 후 낙하 → 새로운 매칭 자동 발생 → 연쇄 카운트 증가
- **방해 뿌요(Ojama)**: 연쇄 발생 시 상대에게 전송, 매칭 안 됨, 인접 뿌요 제거 시 소멸
- **고스트 뿌요(Ghost Puyo)**: 화면 위쪽(y ≥ 12)에 있는 뿌요는 충돌 체크 무시 (스폰 시 상단 뿌요만 보여도 좌우 이동 가능)
- **락 딜레이 (Lock Delay) - Tsu 규칙**: 바닥에 닿은 후 0.5초 동안 이동/회전 가능 (최대 15회), 초과 시 즉시 잠금

### 뿌요뿌요 2만의 핵심 시스템

| 시스템                          | 설명                                                                                       |
| ------------------------------- | ------------------------------------------------------------------------------------------ |
| **오프셋(Offset) 룰**           | 내 필드에 방해 뿌요 있을 때 연쇄 발생 → 내 방해 뿌요부터 상쇄, 남은 연쇄력만 상대에게 전송 |
| **마진 타임(Margin Time)**      | 시간 경과 시 연쇄당 방해 뿌요 배수 증가 (장기전 방지)                                      |
| **올 클리어(All Clear) 보너스** | 필드 완전 비우기 → 다음 연쇄에 추가 방해 뿌요 보너스                                       |
| **더블 회전(Double Rotation)**  | 양옆 막혔을 때 180도 회전 가능 (벽킥)                                                      |

### 화면 방향 및 레이아웃 전략 (v0.2.0~)

**전체 가로 고정 (Landscape Only)** - 모바일/데스크톱 동일

| 플랫폼               | 방향      | 해상도 (가상) | 비고                                            |
| -------------------- | --------- | ------------- | ----------------------------------------------- |
| **모바일 (Android)** | 가로 고정 | 1600×960      | AndroidManifest `screenOrientation="landscape"` |
| **데스크톱 (PC)**    | 가로 고정 | 1600×960      | LWJGL3 창 크기 고정, 리사이즈 시 비율 유지      |

> **이유**: 뿌요뿌요2 아케이드/콘솔 원작이 가로 화면 기준. 대전 모드(두 보드 나란히) 및 싱글 모드(보드+사이드 패널) 모두 가로 레이아웃이 최적.

#### 모드별 레이아웃

| 모드                       | 레이아웃 구조                          | 가상 좌표 (1600×960)                       |
| -------------------------- | -------------------------------------- | ------------------------------------------ |
| **싱글 (스토리/엔드리스)** | [보드 480×960] [사이드 패널 ~1000×960] | 보드: (80, 0), 사이드: (600, 0)            |
| **대전 (VS/AI)**           | [P1보드 480] [중앙UI 200] [P20]        | P1: (220, 0), 중앙: (700, 0), P2: (900, 0) |

#### 모바일 터치 컨트롤러 (전 모드 공통)

```
┌─────────────────────────────────────────────────────────────────┐
│ 1600 (가로)                                                     │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  [게임 영역: 싱글=보드+사이드 / 대전=P1보드|중앙|P2보드]         │
│                                                                 │
│  ┌─────────────────────┐                    ┌───────────────┐  │
│  │      ◀    ▶         │                    │    ↻    ▼     │  │
│  │   좌이동  우이동     │                    │  회전  빠른낙하 │  │
│  │                     │                    │               │  │
│  │  [왼쪽 엄지 영역]    │                    │ [오른쪽 엄지 영역]│  │
│  └─────────────────────┘                    └───────────────┘  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

| 버튼         | 위치             | 동작                                                                         |
| ------------ | ---------------- | ---------------------------------------------------------------------------- |
| **◀ 좌이동** | 좌하단           | 누름 유지 → 왼쪽 이동                                                        |
| **▶ 우이동** | 좌하단 (좌측 옆) | 누름 유지 → 오른쪽 이동                                                      |
| **↻ 회전**   | 우하단 (상단)    | 탭 → 90도 시계방향 회전                                                      |
| **▼ 드롭**   | 우하단 (하단)    | **탭**: 소프트 드롭 시작/유지, **더블 탭(300ms)**: 하드 드롭(즉시 낙하+고정) |

> **조작 방식**: 양손 엄지 최적화 (한손 플레이 불가 - 이동+회전 동시 입력 필요)
>
> - 왼쪽 엄지: 좌우 이동 (가로 배치)
> - 오른쪽 엄지: 회전/드롭 (세로 배치)

| 플랫폼     | 대전 방식                 | 비고                                                                     |
